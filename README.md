# OM AI Toolkit

面向运营管理（Operations Management，OM）研究者的 AI 协作入门项目，计划提供中文教程、通用技能和可复现示例。

**当前状态：本地筹备 · 首页草稿 R1。** 目前只有项目说明与维护文件，尚未纳入技能、脚本或示例，也没有可安装的发布版本。

## 从一个科研小任务开始

本项目适合熟悉自己的研究问题、但刚开始尝试 AI 协作的研究者。无需先搭建复杂系统，先学习如何说清输入、需要的结果和检查标准，再让 AI 协助完成一个有边界的小任务。

第一批内容拟围绕“从公式到可编辑科研图”展开。目标是让每个示例都能回答三个问题：需要准备什么、如何完成、怎样确认结果可靠。

| 计划模块 | 要解决的问题 | 预期示例产物 |
| --- | --- | --- |
| Mathematica 区域图 | 将模型条件转成区域图，核对可行域、边界和代表点 | 可运行的绘图源文件与检查说明 |
| Visio 图形重建 | 根据参考图重建图形、文字和连线，便于后续修改 | 可编辑的 Visio 文件 |
| MathType 公式 | 在科研图或 Office 文档中保留可继续编辑的公式 | 含可编辑公式的文件与检查说明 |

以上均为计划模块，尚未提供下载或运行入口。具体软件版本、所需许可和支持环境将在示例实际验证后说明；项目不包含商业软件安装程序，也不代办软件授权。

## 现在怎样开始

1. 阅读本页，了解项目准备解决的小任务。
2. 阅读[公开范围说明](PUBLIC_SCOPE.md)，了解哪些材料可以进入项目。
3. 选择一个不含私人资料、允许分享的简单任务，说明输入、期望文件和完成标准。现阶段只准备任务描述，待首个示例补齐后再跟做。

未来的教程将从一次完整的小任务入手：负责人接收需求，安排执行，检查产物，再交付结果。研究者负责研究目标和最终判断；AI 的生成结果需要结合公式、源文件和实际运行情况核对。
