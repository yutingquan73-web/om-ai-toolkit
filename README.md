# OM AI Toolkit

面向运营管理（Operations Management，OM）研究者的 AI 协作入门项目，计划提供中文教程、通用技能和可复现示例。

首发包含 Mathematica 区域图技能、三工艺成本比较教程、源码、Notebook 和图形预览。案例已在 Mathematica 13.3.1 中运行，并完成数学核对和导出图形检查。

## 从一个科研小任务开始

本项目适合熟悉自己的研究问题、但刚开始尝试 AI 协作的研究者。无需先搭建复杂系统，先学习如何说清输入、需要的结果和检查标准，再让 AI 协助完成一个有边界的小任务。

第一批内容拟围绕“从公式到可编辑科研图”展开。目标是让每个示例都能回答三个问题：需要准备什么、如何完成、怎样确认结果可靠。

| 计划模块 | 要解决的问题 | 预期示例产物 |
| --- | --- | --- |
| [Mathematica 区域图：首个教学模块](examples/01-process-choice/README.md) | 将模型条件转成区域图，核对可行域、边界和代表点 | 已提供技能、教程、源码、notebook 和经检查的图形预览 |
| Visio 图形重建 | 根据参考图重建图形、文字和连线，便于后续修改 | 可编辑的 Visio 文件 |
| MathType 公式 | 在科研图或 Office 文档中保留可继续编辑的公式 | 含可编辑公式的文件与检查说明 |

首发范围已确定为现有 Mathematica 技能与三工艺教学案例。模块的已完成检查和未验证部分见[验证记录](examples/01-process-choice/VALIDATION.md)。Visio 与 MathType 留待后续，不纳入首发。项目不包含商业软件安装程序，也不代办软件授权。

## 现在怎样开始

1. 从[示例 01：三种生产工艺的选择](examples/01-process-choice/README.md)开始，先理解模型、边界和预期结果，再按教程尝试运行。
2. 若希望 AI 协助，给它阅读[通用绘图技能](skills/mathematica-region-plot/SKILL.md)，并使用教程中的任务提示。直接跟做本例无需先安装技能；已有同名技能时不要覆盖。
3. 准备自己的材料前，阅读[公开范围说明](PUBLIC_SCOPE.md)。输入、期望文件和检查标准应说清楚，私人资料不进入这个项目。

未来的教程将从一次完整的小任务入手：负责人接收需求，安排执行，检查产物，再交付结果。研究者负责研究目标和最终判断；AI 的生成结果需要结合公式、源文件和实际运行情况核对。
